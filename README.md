# Car Evaluation Dashboard – Power BI

## Project Overview

This project is an interactive **Car Evaluation Dashboard developed using Microsoft Power BI**. It uses the Car Evaluation dataset to analyze vehicle characteristics and present insights through interactive visualizations and dashboard elements.

## Problem Statement

Car evaluation datasets contain multiple attributes that can be difficult to compare using raw tables. The project addresses this by transforming the dataset into an interactive business-style dashboard.

## Objective

* Import and prepare the Car Evaluation dataset.
* Analyze important vehicle attributes.
* Build interactive visualizations.
* Identify patterns in car evaluation categories.
* Present insights through an intuitive dashboard.

## Technologies Used

* Microsoft Power BI
* Power Query
* Data Cleaning
* Data Visualization
* DAX

## Key Features

* Interactive dashboard.
* KPI-style summary information.
* Visual analysis of car evaluation categories.
* Analysis of buying and maintenance costs.
* Comparison of safety, capacity, and other vehicle attributes.
* Interactive filters and slicers.
* Easy exploration of trends and patterns.

## Outcome

The Power BI dashboard transforms the Car Evaluation dataset into an interactive analytical report, making it easier to compare vehicle attributes, identify patterns, and understand factors associated with car acceptability.
